# 🚀 快速操作指南

## 1️⃣ 启动系统（第一次操作）

```bash
cd /home/cake/机器人导论/final_project
./start_system.sh
```

等待看到："🎉 系统启动完成！"

## 2️⃣ 系统界面

启动后会出现**2个窗口**：

### Gazebo窗口（左边）
- 3D仿真环境
- 蓝白色小车 = 机器人
- 红色圆柱 = 障碍物

### RViz窗口（右边）  
- 2D地图界面
- 黑色 = 障碍物
- 白色 = 可通行区域
- 红色箭头 = 机器人位置

## 3️⃣ 控制机器人（核心操作）

### 在RViz窗口中：
1. **点击工具栏的绿色箭头图标**（"2D Nav Goal"）
2. **在白色区域点击**设置目标位置
3. **拖拽鼠标**设置到达时的朝向
4. **松开鼠标**确认目标

### 立即发生的事情：
- 终端显示"收到目标点"
- 绿色线条出现（搜索树）
- 红色路径出现（规划路径）
- 机器人开始移动

## 4️⃣ 观察重点

### 在RViz中观察：
- **绿色细线**：路径搜索过程
- **红色粗线**：最终选择的路径
- **蓝色轨迹**：机器人实际走的路

### 在Gazebo中观察：
- 机器人的实际运动
- 避障行为
- 运动流畅性

### 在终端中观察：
- 规划时间（越短越好）
- 路径长度
- 实时控制信息

## 5️⃣ 性能评估

系统自动评估4个指标（每个15分）：

1. **规划时间**：看终端输出，目标 < 1秒
2. **路径长度**：看终端数值，应该合理避障
3. **跟踪精度**：看蓝色轨迹与红色路径的偏差
4. **速度平滑**：看机器人运动是否平稳

## 6️⃣ 实验建议

### 第一次尝试：
- 设置近距离目标（2-3米）
- 选择明显的白色区域
- 观察完整过程

### 进阶测试：
- 尝试不同距离的目标
- 测试需要绕障的路径
- 多次测试同一目标比较稳定性

## 7️⃣ 常见问题快速解决

| 问题 | 解决方法 |
|------|----------|
| 机器人不动 | 重新选择白色区域设置目标 |
| 没有路径显示 | 等待几秒，或重启系统 |
| RViz显示异常 | 重启RViz：关闭窗口再重新启动 |
| Gazebo卡死 | 重启整个系统 |

## 8️⃣ 停止系统

```bash
./stop_system.sh
```

或按 `Ctrl+C` 停止
