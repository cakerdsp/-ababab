## 2. 控制流程时序图

```mermaid
sequenceDiagram
    participant U as 👤 用户
    participant R as 🖥️ RViz
    participant P as 🧠 路径规划器
    participant C as 🎯 控制器
    participant G as 🌍 Gazebo
    participant T as 💻 终端
    
    Note over U,T: 系统启动完成
    
    U->>R: 1. 点击"2D Nav Goal"工具
    U->>R: 2. 在地图上设置目标点
    R->>P: 3. 发送目标点坐标
    
    Note over P: 开始RRT*路径规划
    P->>T: 4. 显示"收到目标点"
    P->>T: 5. 显示"开始RRT*路径规划"
    P->>R: 6. 发布搜索树(绿色线条)
    
    Note over P: 找到最优路径
    P->>R: 7. 发布最优路径(红色线条)
    P->>C: 8. 发送路径点序列
    P->>T: 9. 显示规划时间和路径长度
    
    Note over C: 开始路径跟踪
    C->>T: 10. 显示"开始路径跟踪"
    loop 路径跟踪循环
        C->>G: 11. 发送速度指令
        G->>C: 12. 反馈当前位置
        C->>R: 13. 更新机器人位置(红色箭头)
        C->>R: 14. 绘制实际轨迹(蓝色线条)
    end
    
    Note over U,T: 用户观察结果
    U->>G: 15. 观察3D机器人运动
    U->>R: 16. 观察2D路径和轨迹对比
    U->>T: 17. 查看性能数据
```

## 如何使用这些图表

### 方法1：在线查看（最简单）
1. 访问 https://mermaid.live/
2. 复制上面的代码（包括 ```mermaid 和 ``` ）
3. 粘贴到编辑器中即可看到图表

### 方法2：VS Code查看
1. 安装"Mermaid Preview"插件
2. 创建.md文件，粘贴上面的代码
3. 右键选择"Open Preview"

### 方法3：导出图片
1. 在 https://mermaid.live/ 中编辑
2. 点击"Actions" -> "Download PNG/SVG"
3. 保存为图片文件

### 方法4：集成到文档
- 可以直接复制到任何支持Mermaid的Markdown文档中
- GitHub、GitLab等平台会自动渲染
