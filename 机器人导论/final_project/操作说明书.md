## 🎯 系统概述

这是一个完整的机器人路径规划与跟踪系统，包含以下核心功能：
- **Gazebo仿真**：3D物理仿真环境
- **随机障碍物生成**：自动生成环境障碍物
- **2D栅格地图**：从3D环境生成2D占用栅格地图
- **RRT*路径规划**：智能路径规划算法
- **PID路径跟踪**：精确的路径跟踪控制
- **RViz可视化**：实时显示规划过程和结果

## 🚀 启动系统

### 第一步：启动系统
```bash
cd /home/cake/机器人导论/final_project
./start_system.sh
```

### 第二步：等待系统初始化
系统启动需要约10-15秒，你会看到：
1. **编译工作空间** - 确保所有代码最新
2. **启动roscore** - ROS核心服务
3. **启动Gazebo** - 3D仿真环境（会弹出窗口）
4. **生成障碍物** - 在环境中随机放置障碍物
5. **生成地图** - 创建2D栅格地图
6. **启动路径规划器** - RRT*算法准备就绪
7. **启动控制器** - PID控制器准备就绪
8. **启动RViz** - 可视化界面（会弹出窗口）

## 🖥️ 界面介绍

启动成功后，你会看到**两个主要窗口**：

### 1. Gazebo窗口（3D仿真环境）
- **用途**：显示真实的3D仿真环境
- **内容**：
  - 灰色平面：地面
  - 红色圆柱体：随机生成的障碍物
  - 蓝白色小车：TurtleBot3机器人
- **操作**：
  - 鼠标左键拖拽：旋转视角
  - 鼠标滚轮：缩放
  - 鼠标中键拖拽：平移视角

### 2. RViz窗口（2D可视化界面）
- **用途**：显示2D地图、路径规划和机器人状态
- **主要显示内容**：
  - 黑白网格：2D占用栅格地图（黑色=障碍物，白色=自由空间）
  - 红色箭头：机器人当前位置和朝向
  - 绿色线条：RRT*搜索树
  - 红色粗线：规划的最优路径
  - 蓝色轨迹：机器人实际运动轨迹

## 📱 详细操作步骤

### 步骤1：等待系统完全启动
- 观察终端输出，等待看到："🎉 系统启动完成！"
- 确保Gazebo和RViz窗口都已打开并完全加载

### 步骤2：设置导航目标
#### 方法一：使用RViz界面（推荐）
1. **在RViz窗口中**，找到工具栏
2. **点击 "2D Nav Goal" 工具**（看起来像一个绿色箭头的图标）
3. **在地图上点击**你想让机器人去的位置（白色区域，避开黑色障碍物）
4. **拖拽鼠标**设置机器人到达目标时的朝向
5. **松开鼠标**确认目标

#### 方法二：使用命令行（高级用户）
```bash
# 发布目标点命令示例
rostopic pub /move_base_simple/goal geometry_msgs/PoseStamped "header:
  seq: 0
  stamp:
    secs: 0
    nsecs: 0
  frame_id: 'map'
pose:
  position:
    x: 3.0
    y: 2.0
    z: 0.0
  orientation:
    x: 0.0
    y: 0.0
    z: 0.0
    w: 1.0"
```

### 步骤3：观察路径规划过程
设置目标后，系统会自动：
1. **接收目标点**：终端显示"收到目标点: (x, y)"
2. **开始路径规划**：显示"开始RRT*路径规划..."
3. **显示规划结果**：
   - 迭代次数
   - 规划时间
   - 路径长度
   - 路径点坐标

### 步骤4：观察机器人运动
1. **在Gazebo中**：观察蓝白色机器人开始移动
2. **在RViz中**：观察红色箭头沿着规划路径移动
3. **在终端中**：查看控制器反馈信息

## ⚙️ 系统工作流程

```
用户设置目标 → RRT*路径规划 → 路径优化 → PID控制 → 机器人运动
     ↓              ↓            ↓         ↓          ↓
   RViz界面     终端显示进度    可视化路径   速度控制   Gazebo显示
```

### 详细流程：
1. **目标接收**：RViz接收用户点击的目标点
2. **坐标转换**：将RViz坐标转换为机器人坐标系
3. **路径规划**：RRT*算法在栅格地图上搜索可行路径
4. **路径优化**：移除冗余路径点，平滑路径
5. **路径发布**：将路径发送给控制器
6. **路径跟踪**：PID控制器控制机器人沿路径运动
7. **实时反馈**：持续监控位置，调整控制指令

## 🎨 可视化内容说明

### RViz中的显示元素：

#### 1. 栅格地图 (Grid Map)
- **黑色格子**：障碍物区域（不可通行）
- **白色格子**：自由空间（可通行）
- **灰色格子**：未知区域
- **分辨率**：每格代表0.1米 × 0.1米

#### 2. 机器人位置 (Robot Pose)
- **红色箭头**：机器人当前位置和朝向
- **箭头指向**：机器人前进方向
- **大小**：反映机器人实际尺寸

#### 3. RRT*搜索树 (RRT* Tree)
- **绿色细线**：搜索过程中探索的路径
- **分支结构**：展示算法如何探索空间
- **密度**：反映搜索的彻底程度

#### 4. 规划路径 (Planned Path)
- **红色粗线**：最终选择的最优路径
- **路径点**：离散的路径节点
- **平滑度**：经过优化的路径

#### 5. 机器人轨迹 (Robot Trail)
- **蓝色线条**：机器人实际走过的路径
- **对比**：与红色规划路径的偏差
- **连续性**：反映跟踪精度

### Gazebo中的显示元素：

#### 1. 环境元素
- **灰色地面**：仿真环境的地面
- **红色圆柱**：随机生成的障碍物
- **光照效果**：增强视觉效果

#### 2. 机器人模型
- **TurtleBot3 Burger**：蓝白色差分驱动机器人
- **实时运动**：跟随控制指令运动
- **物理仿真**：真实的惯性和摩擦力

## 📊 性能评估

系统提供四个关键性能指标的实时评估：

### 1. 规划时间 (Planning Time) - 15分
- **观察位置**：终端输出
- **显示格式**：`规划时间: X.XXX 秒`
- **评估标准**：
  - 优秀：< 0.1秒
  - 良好：0.1-1.0秒
  - 一般：1.0-5.0秒
  - 需要改进：> 5.0秒

### 2. 路径长度 (Path Length) - 15分
- **观察位置**：终端输出 + RViz可视化
- **显示格式**：`路径长度: X.XXX 米`
- **评估方法**：
  - 比较不同目标点的路径长度
  - 观察是否接近理论最短路径
  - 检查路径是否合理避障

### 3. 跟踪精度 (Tracking Accuracy) - 15分
- **观察位置**：RViz中红色路径 vs 蓝色轨迹
- **评估方法**：
  - 观察蓝色轨迹与红色路径的偏差
  - 测量最大偏离距离
  - 检查转弯处的跟踪表现
- **数值显示**：终端中的位置误差信息

### 4. 速度平滑度 (Velocity Smoothness) - 15分
- **观察位置**：Gazebo中机器人运动 + 终端速度输出
- **评估标准**：
  - 加速是否平稳
  - 转弯是否顺畅
  - 是否有突然的停止或加速
  - 整体运动是否自然

## ❗ 常见问题与解决方案

### 1. 机器人不移动
**可能原因**：
- 目标点设置在障碍物上
- 路径规划失败
- 控制器未接收到路径

**解决方法**：
- 重新设置目标点到白色区域
- 检查终端是否有错误信息
- 重启系统：`./stop_system.sh` 然后 `./start_system.sh`

### 2. RViz显示异常
**可能原因**：
- RViz配置加载失败
- 话题连接问题

**解决方法**：
- 关闭RViz，手动启动：`rosrun rviz rviz -d src/random_map_generator/final.rviz`
- 检查话题：`rostopic list`

### 3. 路径规划失败
**可能原因**：
- 目标点不可达
- 地图加载失败
- 规划器参数问题

**解决方法**：
- 选择更近的目标点
- 检查地图是否正确显示
- 查看终端错误信息

### 4. Gazebo窗口无响应
**可能原因**：
- GPU资源不足
- Gazebo进程卡死

**解决方法**：
- 关闭其他程序释放资源
- 重启Gazebo：`killall gzserver gzclient`

## 🛑 系统停止

### 安全停止系统
```bash
./stop_system.sh
```

### 手动停止（如果脚本失败）
```bash
# 停止所有ROS节点
rosnode kill -a

# 停止roscore
killall roscore rosmaster

# 停止Gazebo
killall gzserver gzclient

# 停止RViz
killall rviz
```

### 清理环境
```bash
# 清理ROS日志（可选）
rosclean purge

# 重置终端
reset
```
