b) 先查找选修过2017年之前的，减去这个结果集即可

```sql
select student.ID, student.name 
from student
where not exists (
select 1
from takes
where takes.ID = student.ID and takes.year < 2017
)
```

d) 利用c)结果和集合函数min

```sql
with dept_max_salary(dept_name,max_salary) as 
(select dept_name, max(salary) as max_salary
from instructor
group by dept_name
)
select min(max_salary)
from dept_max_salary
```

   5. a) 思路是找出每一个用户的所有分行账户，用brooklyn所有分行去与该用户所有分行作“差集”，并通过判断是否为空来实现目的，若为空，则说明该用户有brooklyn所有分行的账户，是所要找目标客户，否则不是。

   ```sql
   select distinct d.ID
   from depositor d
   where not exists (
   (
   select branch_name
   from branch
   where branch.branch_city = 'Brooklyn'
   )
   except 
   (
   select a.branch_name
   from depositor d2 join account a on d2.account_number = a.account_number
   where d.ID = d2.ID
   )
   )

   ```
