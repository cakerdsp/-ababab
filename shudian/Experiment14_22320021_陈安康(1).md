# 实验十四：特殊计数器的实现

## 一、 实验目的

1. 熟悉JK触发器的逻辑功能。
2. 掌握使用JK触发器搭建特殊计数器的设计方法。

### 二、 实验设备：

1. 数字电路实验箱、逻辑分析仪。
3. 器件：74LS73，74LS00，74LS08，74LS20 等。

## 三、实验原理：

同实验指导书。

## 四、方法与步骤：

依据指导书中所给出的状态转移图，首先列出次态卡诺图：

| $Q^{n}_3Q^{n}_2\ Q^{n}_1Q^{n}_0$ | 00   | 01   | 11   | 10   |
| ---------------------------------- | ---- | ---- | ---- | ---- |
| 00                                 | X    | 1010 | 0010 | 0001 |
| 01                                 | 0011 | 0100 | 0110 | 0101 |
| 11                                 | X    | X    | X    | X    |
| 10                                 | 0111 | 1000 | X    | 1001 |

接下来得到每一位的次态卡诺图，以及经过化简之后，对照JK触发器特征方程得到的触发方程（为了简便，卡诺图中为0的部分没有写）。

$Q^{n + 1}_0$:

| $Q^{n}_3Q^{n}_2\ Q^{n}_1Q^{n}_0$ | 00 | 01 | 11 | 10 |
| ---------------------------------- | -- | -- | -- | -- |
| 00                                 | X  |    |    | 1  |
| 01                                 | 1  |    |    | 1  |
| 11                                 | X  | X  | X  | X  |
| 10                                 | 1  |    | X  | 1  |

$$
J_0 = K_0 = 1
$$

$Q^{n + 1}_1$:

| $Q^{n}_3Q^{n}_2\ Q^{n}_1Q^{n}_0$ | 00 | 01 | 11 | 10 |
| ---------------------------------- | -- | -- | -- | -- |
| 00                                 | X  | 1  | 1  |    |
| 01                                 | 1  |    | 1  |    |
| 11                                 | X  | X  | X  | X  |
| 10                                 | 1  |    | X  |    |

$$
J_1=\overline{Q_0^n} + \overline{Q_3^n + Q_2^n} \quad K_1 = \overline{Q_0^n}
$$

$Q^{n + 1}_2$:

| $Q^{n}_3Q^{n}_2\ Q^{n}_1Q^{n}_0$ | 00 | 01 | 11 | 10 |
| ---------------------------------- | -- | -- | -- | -- |
| 00                                 | X  |    |    |    |
| 01                                 |    | 1  | 1  | 1  |
| 11                                 | X  | X  | X  | X  |
| 10                                 | 1  |    | X  |    |

$$
J_2 = Q_3^n\overline{Q_1^n}\overline{Q_0^n}\quad K_2 = \overline{Q_0^n + \overline{Q_3^n}Q_1^n}
$$

$Q^{n + 1}_3$:

| $Q^{n}_3Q^{n}_2\ Q^{n}_1Q^{n}_0$ | 00 | 01 | 11 | 10 |
| ---------------------------------- | -- | -- | -- | -- |
| 00                                 | X  | 1  |    |    |
| 01                                 |    |    |    |    |
| 11                                 | X  | X  | X  | X  |
| 10                                 |    | 1  | X  | 1  |

$$
J_3 = \overline{Q_2^n}Q_0^n\overline{Q_1^n} \quad K_3= \overline{\overline{Q_2^n}(Q_0^n + Q_1^n)}
$$

以此电路进行连接时，对应的卡诺图中原为X部分的位置是：

|    | 00   | 01   | 11   | 10   |
| -- | ---- | ---- | ---- | ---- |
| 00 | 0011 |      |      |      |
| 01 |      |      |      |      |
| 11 | 0011 | 0100 | 0110 | 0001 |
| 10 |      |      | 1010 |      |

可以看到，异常计数状态的下一个状态都是合法状态，因此可以完成自启动，电路设计合理。

## 六、分析与讨论

通过这次实验，归纳得到时序电路逻辑设计大体遵循以下步骤：

明确状态转移过程（画出状态转移图）-> 明确电路所需触发器数目 -> 画出次态卡诺图并进行化简 -> 依据触发器的特征方程得到触发器的驱动方程 -> 检查自启动 -> 连接电路进行功能验证。

通过这次实验，我练习了时序逻辑电路得设计方法，提高了自己的电路设计与解决问题的能力，受益匪浅。
