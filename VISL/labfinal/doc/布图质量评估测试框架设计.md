## 🔬 **评估指标和方法**

### **4.1 准确度评估**

#### **Feedthrough准确度**
```python
def evaluate_feedthrough_accuracy(predicted, ground_truth):
    # 绝对误差
    absolute_error = abs(predicted - ground_truth)
    # 相对误差
    relative_error = absolute_error / max(ground_truth, 1)
    # 准确度
    accuracy = 1 - relative_error
    return {
        'absolute_error': absolute_error,
        'relative_error': relative_error, 
        'accuracy': accuracy
    }
```

### **4.2 性能评估**

#### **运行时间测试**
```python
def benchmark_performance(algorithms, datasets, iterations=100):
    results = {}
    for algo_name, algorithm in algorithms.items():
        for dataset_name, dataset in datasets.items():
            times = []
            for i in range(iterations):
                start = time.time()
                algorithm.evaluate(dataset)
                times.append(time.time() - start)
            results[f"{algo_name}_{dataset_name}"] = {
                'mean_time': np.mean(times),
                'std_time': np.std(times),
                'min_time': np.min(times),
                'max_time': np.max(times)
            }
    return results
```
