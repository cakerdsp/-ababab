# 存储清理功能说明

## 📁 关于 `flow_system_device_*.json` 文件

### 文件来源和命名规则
- **生成位置**: `UnifiedStorage.saveDeviceState()` 方法
- **命名规则**: `flow_system_device_{设备ID}.json`
- **存储位置**: 应用的 `userData/storage/` 目录

### 文件示例
```
flow_system_device_midea_midea_ac_eyfpek.json        # 美的空调状态
flow_system_device_xiaomi_mi_temp_hum_sensor_u5j8ca.json  # 小米温湿度传感器状态
flow_system_device_xiaomi_mi_air_sensor_39cczg.json # 小米空气质量传感器状态
```

### 文件内容和用途
- **缓存设备状态**: 存储设备的实时状态信息（温度、湿度、开关状态等）
- **提高性能**: 避免重复API调用，提升应用响应速度
- **离线访问**: 在网络断开时提供设备状态数据
- **包含时间戳**: 记录最后更新时间，用于数据有效性判断

### 典型文件内容
```json
{
  "power": "ON",
  "temperature": 26,
  "mode": "cool",
  "lastUpdated": "2025-06-13T13:10:51.320Z"
}
```

## 🛠️ 存储清理功能

### 问题修复
之前的登出功能无法完全删除本地存储文件，现已修复：

1. **添加了 `clearAllDataCompletely()` 方法**
   - 彻底删除所有存储文件和目录
   - 递归删除子目录
   - 详细的操作日志和错误处理

2. **增强了 `clearAllData()` 方法**
   - 改进了文件删除逻辑
   - 添加了详细的调试信息

3. **修复了 AccountManager 登出流程**
   - 使用异步操作确保完整清理
   - 添加了清理结果统计

### 使用方法

#### 前端调用（推荐）
```javascript
// 普通登出（清理应用数据）
const result = await window.api.logout();

// 强制清理所有存储（调试用）
const result = await window.api.forceCleanupStorage();

// 查看存储状态
const status = await window.api.getStorageStatus();
```

#### 后端调用
```javascript
// 在AccountManager中
const result = await accountManager.logout();

// 强制完整清理
const result = accountManager.forceCompleteCleanup();

// 在UnifiedStorage中
const result = storage.clearAllDataCompletely();
```

### 清理级别

1. **标准清理** (`clearAllData`)
   - 删除所有应用数据文件
   - 保留存储目录结构
   - 适用于一般的数据重置

2. **完整清理** (`clearAllDataCompletely`)
   - 删除所有文件和目录
   - 完全移除存储目录
   - 适用于彻底的清理需求

### 清理结果示例
```javascript

  deletedFiles: 12,
  deletedDirectories: 1,
  failedFiles: 0,

```

## 🔧 调试和验证

### 检查存储状态
```javascript
const status = await window.api.getStorageStatus();
console.log(status);
```

输出示例：
```javascript
{
  success: true,
  storageDirectory: "C:\\Users\\...\\userData\\storage",
  totalFiles: 0,
  totalSize: 0,
  isEmpty: true,
  message: "Storage directory is empty"
}
```

### 手动清理存储（调试用）
如果自动清理失败，可以手动调用强制清理：
```javascript
const result = await window.api.forceCleanupStorage();
```

## ⚠️ 注意事项

1. **数据不可恢复**: 清理操作不可逆，请确保重要数据已备份
2. **性能影响**: 清理后首次使用需要重新加载设备状态
3. **调试功能**: `forceCleanupStorage` 仅用于调试，正常使用请用 `logout`
4. **权限要求**: 清理操作需要文件系统写权限
