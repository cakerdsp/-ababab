# 场景设备列表修复报告

## 问题概述

用户在场景控制页面中遇到以下问题：

- **设备列表为空**: 在"添加设备动作"部分，设备下拉列表显示为空
- **无法添加设备**: 无法为场景添加当前分组下的设备动作

## 问题分析

通过详细的调试分析，发现了问题的根本原因：

### 🔍 **核心问题**: Props 传递缺失

**问题位置**: `src/renderer/src/views/children/group/index.vue:149`

```vue
<!-- 修复前 - 缺少 currentGroup 传递 -->
<SceneModeControl />

<!-- 修复后 - 正确传递 currentGroup -->
<SceneModeControl :current-group="currentGroup" />
```

### 📊 **数据流分析**

1. **设备数据存在**: 通过检查存储文件确认设备数据完整

   - 存储位置: `C:\Users\86135\AppData\Roaming\flow-system\storage\flow_system_devices.json`
   - 设备总数: 9个设备
   - 实际分组: `group_1749872177891_kh1tfieij`
2. **分组ID不匹配**:

   - 前端传递的分组ID: `group_1749871023744_1zz6wqq5c` (默认值)
   - 实际设备分组ID: `group_1749872177891_kh1tfieij`
   - 导致设备过滤结果为空
3. **Props传递链断裂**:

   ```
   父组件 (index.vue) → SceneModeControl 组件
        ❌ 缺少 :current-group="currentGroup"
   ```

## 修复方案

### 🔧 **1. 修复Props传递**

**文件**: `src/renderer/src/views/children/group/index.vue`

```vue

<div v-if="currentMode === 'scene'">
  <SceneModeControl :current-group="currentGroup" />
```
