# 🚀 Flow System 运行项目指南

## 🎯 概述

本文档详细说明如何正确运行Flow System项目，并解决常见的运行问题。

## ⚠️ 当前问题分析

### 问题1: package.json未找到错误
```
npm error enoent Could not read package.json: Error: ENOENT: no such file or directory, 
open 'D:\flow-system-master-5.27\package.json'
```

**原因**: 你当前在错误的目录中执行命令，应该在 `D:\flow-system-master-5.27\flow-system-master-5.27\` 目录执行。

**解决方案**: 需要切换到正确的项目目录。

### 问题2: JavaScript错误 - IPC参数转换失败
```
TypeError: Error processing argument at index 0, conversion failure from
at IpcMainImpl.<anonymous> (D:\flow-system-master-5.27\flow-system-master-5.27\out\main\index.js:29:16)
```

**原因**: 登录时发送的IPC消息参数类型不正确，主进程无法处理。

**解决方案**: 需要修复登录页面的IPC调用。

## 🔧 问题修复方案

### 修复IPC调用错误

由于登录页面的IPC调用存在问题，需要进行以下修复：

**问题位置**: `src/renderer/src/views/login/index.vue` 第159行左右

**当前代码**:
```javascript
window.ipcRenderer.send('toMain', {
  username: this.loginObj.username,
  token: '',
  screenWidth: screenWidth,
  screenHeight: screenHeight
})
```

**修复方案**: 
1. 确保screenWidth和screenHeight是数字类型
2. 添加错误处理
3. 使用更安全的IPC调用方式

## 🚨 常见问题排查

### 问题1: 端口占用
```
Error: listen EADDRINUSE: address already in use :::9080
```
**解决**: 更换端口或关闭占用端口的进程
```bash
# 查看端口占用
netstat -ano | findstr :9080

# 杀死进程 (替换PID)
taskkill /pid <PID> /f
```

### 问题2: 权限问题
```
Error: EPERM: operation not permitted
```
**解决**: 以管理员身份运行PowerShell

### 问题3: 网络问题
```
npm ERR! network request failed
```
**解决**: 配置npm镜像源
```bash
npm config set registry https://registry.npmmirror.com/
```

### 问题4: Node版本兼容性
```
Error: The engine "node" is incompatible
```
**解决**: 升级Node.js到推荐版本

### 问题5: 依赖安装失败
```
npm ERR! peer dep missing
```
**解决**: 
```bash
npm install --legacy-peer-deps
```
