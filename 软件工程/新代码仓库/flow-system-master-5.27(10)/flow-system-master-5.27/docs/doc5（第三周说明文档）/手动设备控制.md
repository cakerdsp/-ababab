### 手动控制流程

l 客户端发送控制请求到服务端，客户端需要简单校验属性合法值，和提醒属性值设置范围

l 服务端返回操作结果到客户端，服务端推送设备状态变化到客户端（前面已经完成）



### 设备属性值范围限定

设备状态离线online=0且设备关闭off时不允许控制其他属性

l **小米温湿度计：**

**Temperature(摄氏度): -10 ~60(float)**

**Humidity(%): 0~100(int)**

**Time：时间戳**

l **空气质量检测仪：**

**pm25(μg/m³): 0 ~ 500(int)**

**Temperature和Humidity: 同上**

**（可选：服务端有属性，但是目前客户端和前端没有实现, 暂时不要）**

**(pm10(μg/m3): 0-999(int)**

**co2(ppm): 400-5000(int))**

**      time: 时间戳**

l **空调类：**

**online(bool):0/1**

**target_temperature：16°C ~ 30°C(float) 调节精度0.1**

**fan_speed：low, medium, high, auto (string)**

    **mode(string): cool（制冷）、heat（制热）、dry（除湿）、fan（送风）**

 **power: **  **“**  **ON**  **”**  **/**  **”**  **OF** **”**** （String）**

**模式为dry时不允许调节target_temperature**

l **加湿器：**
**online(bool):0/1**

**power（bool）：0/1**

**status（string）：running, paused,off**

**mode (String): 'auto', 'sleep', 'strong'**

**target_humidity(% int): 30-80 调节精度 1%**

**在status 为 paused 或 off 时，不允许调整 target_humidity（目标湿度），模式为auto时不允许调节target_humidity**

l **除湿器：**
**  online(bool):  0/1**

**power（bool）:0/1**

    **  mode  (String): 'auto', 'sleep', 'dry'**

    **  target_humidity(% int): 30-80 调节精度 1%**

l **空气净化器:**
**online(bool):0/1**

**power(bool): 0/1**

**mode(string): 'auto', 'silent', 'strong'**

**fan_level(int): 1，2，3**

**在power 为 OFF 时，不允许调整 mode（模式）和 fan_level（风扇级别），模式为auto时不允许调节fan_level**

    **客户端提前拦截不合理操作**



### 1. Api设计

请求头：access_token. JWT鉴权

请求地址：device/control （类似即可，具体看前面实现的习惯）

请求方式：POST

请求参数：

    设备码：did

    Control：控制命令对象，包括操作属性operation和操作值value

{

  "did": "189951183333",

  "control": {

    "operation": "power",

    "value": "off"

  }

}

返回结果：

    Code

    操作结果：status

{

    “ code” 200

    “message”： string，（code=200则为success，否则为错误信息，主要为属性不正确或不可控制，设备不存在（不为账号所有），操作不支持）

}

错误码：401鉴权失败

    1001 设备不存在

    1002 属性不存在

    1003 属性值不支持

    1004 操作不支持（关机/离线）

客户端调用服务端时，需要检验命令，检验内容为

设备是否在线online = true （离线不支持任何操作）

设备是否打开on/off（关闭了只支持打开操作）

设备的value设置是否正确，在有效范围内，且是有效精度

（因为前端一般会展示好要控制的设备和可以控制的设备属性，用户只需要选择或者输入数值，这个已经保证了设备在客户端内存中存在，且设备具有该属性）
