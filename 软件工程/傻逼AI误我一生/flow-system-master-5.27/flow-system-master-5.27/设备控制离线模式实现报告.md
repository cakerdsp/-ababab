# 设备控制离线模式实现报告

## 项目概述
为flow-system应用实现设备手动控制功能的离线模式，确保在无网络连接或API服务不可用时，用户仍能控制设备并实时更新本地状态。

## 实现范围

### 1. 离线模式支持的设备类型
- **空调设备** (mi_ac, midea_ac)
  - 电源控制 (power: ON/OFF)
  - 目标温度 (target_temperature: 16-30°C)
  - 风速设置 (fan_speed: low/medium/high/auto)
  - 运行模式 (mode: cool/heat/dry/fan)

- **加湿器** (mi_humidifier, midea_humidifier)
  - 电源控制 (power: 0/1)
  - 运行状态 (status: running/paused/off)
  - 工作模式 (mode: auto/sleep/strong)
  - 目标湿度 (target_humidity: 30-80%)

- **除湿器** (mi_dehumidifier, midea_dehumidifier)
  - 电源控制 (power: 0/1)
  - 工作模式 (mode: auto/sleep/dry)
  - 目标湿度 (target_humidity: 30-80%)

- **空气净化器** (mi_air_purifier, midea_air_purifier)
  - 电源控制 (power: 0/1)
  - 工作模式 (mode: auto/silent/strong)
  - 风扇级别 (fan_level: 1/2/3)

#### 2.2 智能控制逻辑
```javascript
async controlDevice(did, operation, value) {
  // 1. 设备和命令验证
  // 2. 离线模式判断
  if (this.offlineMode || !this.apiRegistry) {
    // 直接执行本地控制
    return await this.executeOfflineControl(did, operation, value);
  }

  // 3. 在线模式API调用
  try {
    const response = await this.apiRegistry.callAPI('controlDevice', params);
    // 成功后更新本地状态
  } catch (error) {
    // API失败自动降级到离线模式
    return await this.fallbackToOfflineMode(did, operation, value);
  }
}
```
