# 场景动作缓冲区和删除功能修复报告

## 📋 问题概述

用户报告了两个关键的场景控制功能问题：

### 问题1：动作缓冲区验证逻辑缺陷

- **现象**: 当设备处于关机状态时，即使在"动作缓冲区"中已添加开机动作，添加其他需要开机的动作（如设置温度）仍会报错"设备关机，不允许操作"
- **根本原因**: 验证逻辑只考虑设备当前状态，没有考虑当前正在编辑的动作列表中的开机动作
- **用户需求**: 如果动作缓冲区中已经包含开机动作，后续动作应该能够正常添加，即使还没有保存

### 问题2：场景动作删除功能失效

- **现象**: 用户点击删除动作按钮后，点击保存，重新打开场景后被删除的动作依旧显示
- **根本原因**: 前端删除动作后，保存时没有正确更新场景的完整动作列表
- **用户需求**: 删除动作后保存，应该真正从场景中移除被删除的动作

## 🔧 修复方案

### 修复1：智能动作缓冲区验证

#### 修复位置

`src/class/modules/device/SceneManager.js` - `validateActionValues()` 方法

#### 核心改进

1. **深拷贝设备状态**：避免修改原始设备对象
2. **智能开机状态检测**：检查动作列表中是否包含开机动作
3. **虚拟状态模拟**：如果有开机动作，临时设置设备为开机状态进行验证
4. **精确错误提示**：针对缺少开机动作的情况给出明确提示

#### 修复代码

```javascript
// 验证动作属性值
validateActionValues(device, actions) {
  if (!this.deviceControlManager) {
    console.log('🟡 [Scene] Device control manager not available, skipping validation');
    return { success: true };
  }

  // 创建一个包含当前动作的虚拟设备状态，用于验证（深拷贝避免修改原始设备）
  const virtualDeviceState = JSON.parse(JSON.stringify(device));

  // 检查动作中是否包含开机指令
  const hasPowerOnAction = actions.some(action =>
    action.operation === 'power' &&
    (action.value === 'ON' || action.value === true || action.value === 1)
  );

  // 检查是否有需要开机的操作
  const deviceType = device.type;
  const powerDependentProps = this.POWER_DEPENDENT_PROPS[deviceType] || [];
  const hasPowerDependentAction = actions.some(action =>
    powerDependentProps.includes(action.operation)
  );

  // 如果有开机动作，临时设置设备为开机状态进行验证
  if (hasPowerOnAction) {
    if (!virtualDeviceState.status) {
      virtualDeviceState.status = {};
    }
    virtualDeviceState.status.power = 'ON';
    virtualDeviceState.online = true;
  } else if (hasPowerDependentAction) {
    // 如果有需要开机的操作但没有开机动作，检查设备当前是否为开机状态
    const currentPowerState = device.status?.power;
    const isCurrentlyOn = currentPowerState === 'ON' || currentPowerState === true || currentPowerState === 1;

    if (!isCurrentlyOn) {
      return {
        success: false,
        message: `设备 ${device.name || device.did} 当前为关机状态，无法执行需要开机的操作。请先添加开机动作。`
      };
    }
  }

  for (const action of actions) {
    const validation = this.deviceControlManager.validateControlCommand(
      virtualDeviceState,
      action.operation,
      action.value
    );

    if (!validation.valid) {
      return {
        success: false,
        message: `设备 ${device.name || device.did} 的动作验证失败: ${validation.message}`
      };
    }
  }

  return { success: true };
}
```

### 修复2：前端动作传递优化

#### 修复位置

`src/renderer/src/components/SceneModeControl.vue` - `addActionToScene()` 方法

#### 核心改进

1. **完整动作列表传递**：验证时传递当前场景的所有动作（包括已有的和正在添加的）
2. **上下文感知验证**：让后端能够看到完整的动作上下文进行智能验证

#### 修复代码

```javascript
// 添加动作到场景
async addActionToScene() {
  if (!this.canAddAction) return;

  // 构建新动作列表
  const newActions = [];
  for (const control of this.deviceControlOptions) {
    const value = this.newAction[control.property];
    if (value !== undefined && value !== '') {
      newActions.push({
        did: this.selectedDeviceForAction,
        operation: control.property,
        value: value
      });
    }
  }

  if (newActions.length === 0) return;

  try {
    console.log('🎬 [场景调试] 验证动作:', newActions);

    // 获取当前场景的所有动作（包括已有的）
    const existingActions = this.currentScene.actions || [];
    const allActions = [...existingActions, ...newActions];

    // 将完整的动作列表转换为纯JavaScript对象，避免IPC传递问题
    const pureActions = JSON.parse(JSON.stringify(allActions));

    // 验证完整的动作列表
    const validateResult = await window.electronAPI.invoke('validate-scene-actions', pureActions);
    if (!validateResult.success) {
      throw new Error(validateResult.message);
    }

    // 验证通过，添加到当前场景
    if (!this.currentScene.actions) {
      this.currentScene.actions = [];
    }
    this.currentScene.actions.push(...newActions);

    // 重置表单
    this.resetActionForm();
    this.showMessage('动作添加成功', 'success');

  } catch (error) {
    console.error('添加动作失败:', error);
    this.showMessage(error.message, 'error');
  }
}
```

### 修复3：场景动作完全替换机制

#### 修复位置

`src/class/modules/device/SceneManager.js` - `updateScene()` 方法

#### 核心改进

1. **支持完全替换模式**：新增 `replaceActions` 参数支持
2. **保持向下兼容**：同时支持原有的增量更新模式
3. **离线模式支持**：确保离线环境下也能正常工作

#### 修复代码

```javascript
async updateScene(sceneId, updateDataOrAddActions = [], removeActionIds = []) {
  // 支持三种调用方式：对象参数（增量更新）、对象参数（完全替换）或独立参数
  let addActions, removeActions, replaceActions;

  if (typeof updateDataOrAddActions === 'object' && updateDataOrAddActions !== null) {
    if (updateDataOrAddActions.replaceActions !== undefined) {
      // 完全替换模式
      replaceActions = updateDataOrAddActions.replaceActions;
      console.log('🔧 [Scene] Replacing scene actions:', { sceneId, replaceActions });
    } else if (updateDataOrAddActions.actions) {
      // 增量更新模式（对象参数）
      addActions = updateDataOrAddActions.actions.add || [];
      removeActions = updateDataOrAddActions.actions.remove || [];
    } else {
      // 独立参数方式
      addActions = updateDataOrAddActions;
      removeActions = removeActionIds;
    }
  } else {
    // 独立参数方式
    addActions = updateDataOrAddActions;
    removeActions = removeActionIds;
  }

  try {
    if (!this.scenes.has(sceneId)) {
      return { success: false, message: '场景不存在' };
    }

    const scene = this.scenes.get(sceneId);

    // 处理完全替换模式
    if (replaceActions !== undefined) {
      // 验证新动作
      if (replaceActions.length > 0) {
        const processedActions = await this.processSceneActions(replaceActions, scene.gid);
        if (!processedActions.success) {
          return processedActions;
        }
        replaceActions = processedActions.data;
      }

      // 检查是否为离线模式
      if (!this.apiRegistry || this.offlineMode) {
        console.log('🟡 [Scene] Offline mode: replacing scene actions locally');

        // 本地替换场景动作
        scene.actions = replaceActions.map((action, index) => ({
          ...action,
          action_id: action.action_id || `action_${Date.now()}_${index}`
        }));
        scene.updated_at = new Date().toISOString();

        // 保存到本地存储
        this.saveScenesToStorage();

        console.log('✅ [Scene] Scene actions replaced successfully in offline mode');
        return {
          success: true,
          message: '场景动作替换成功（离线模式）',
          data: scene
        };
      }

      // 在线模式：调用服务端API
      const response = await this.apiRegistry.callAPIPut('updateScene', {
        scene_id: sceneId,
        actions: replaceActions
      });

      if (response && response.code === 200) {
        // 更新本地缓存
        scene.actions = response.data.actions || replaceActions;
        scene.updated_at = new Date().toISOString();
        this.saveScenesToStorage();

        return {
          success: true,
          message: '场景动作替换成功',
          data: response.data
        };
      } else {
        return {
          success: false,
          message: response?.message || '场景动作替换失败'
        };
      }
    }

    // 原有的增量更新逻辑保持不变...
    // [省略原有代码]

  } catch (error) {
    console.error('Failed to update scene:', error);
    return { success: false, message: '更新场景失败：' + error.message };
  }
}
```

### 修复4：前端保存逻辑优化

#### 修复位置

`src/renderer/src/components/SceneModeControl.vue` - `saveSceneChanges()` 方法

#### 核心改进

1. **使用完全替换模式**：保存时传递完整的动作列表而不是增量更新
2. **确保数据一致性**：避免前后端状态不同步的问题

#### 修复代码

```javascript
// 保存场景更改
async saveSceneChanges() {
  this.saving = true;
  try {
    console.log('🎬 [场景调试] 保存场景更改, 场景ID:', this.currentScene.scene_id);

    // 将响应式对象转换为纯JavaScript对象，避免IPC传递问题
    const sceneActions = JSON.parse(JSON.stringify(this.currentScene.actions || []));

    // 使用完全替换模式，确保前后端状态一致
    const updateData = {
      replaceActions: sceneActions
    };

    console.log('🎬 [场景调试] 更新数据:', updateData);

    const result = await window.electronAPI.invoke('update-scene', this.currentScene.scene_id, updateData);
    if (result.success) {
      this.showMessage('场景配置已保存', 'success');
      this.showSceneDetail = false;
      await this.loadScenes(); // 重新加载场景列表
    } else {
      throw new Error(result.message);
    }
  } catch (error) {
    console.error('保存场景失败:', error);
    this.showMessage('保存失败: ' + error.message, 'error');
  } finally {
    this.saving = false;
  }
}
```
