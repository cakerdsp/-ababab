### 支持的设备类型和属性

#### 🌡️ 空调设备 (mi_ac, midea_ac)
- **power**: ON/OFF - 电源控制
- **target_temperature**: 16°C ~ 30°C (精度0.1) - 目标温度
- **fan_speed**: low/medium/high/auto - 风速档位
- **mode**: cool/heat/dry/fan - 工作模式
- **约束**: 除湿模式下不能调节温度

#### 💧 加湿器设备 (mi_humidifier, midea_humidifier)
- **power**: 0/1 - 电源状态
- **status**: running/paused/off - 运行状态
- **mode**: auto/sleep/strong - 工作模式
- **target_humidity**: 30% ~ 80% (精度1%) - 目标湿度
- **约束**: 暂停/关闭状态或自动模式下不能调节湿度

#### 🌬️ 除湿器设备 (mi_dehumidifier, midea_dehumidifier)
- **power**: 0/1 - 电源状态
- **mode**: auto/sleep/dry - 工作模式
- **target_humidity**: 30% ~ 80% (精度1%) - 目标湿度

#### 🍃 空气净化器设备 (mi_air_purifier, midea_air_purifier)
- **power**: 0/1 - 电源状态
- **mode**: auto/silent/strong - 工作模式
- **fan_level**: 1/2/3 - 风扇等级
- **约束**: 关机状态下不能调节模式和风扇等级；自动模式下不能调节风扇等级

## 🔧 实现细节

### 1. DeviceControlManager 类

**核心职责**:
- 设备控制命令验证
- 设备属性值范围检查
- 设备状态约束规则执行
- API调用和本地状态更新

**关键方法**:
```javascript
// 设备控制核心方法
async controlDevice(did, operation, value)

// 验证控制命令
validateControlCommand(device, operation, value)

// 获取设备控制选项
getDeviceControlOptions(did)

// 获取可控制设备列表
getControllableDevices()
```

### 2. 验证机制

#### 多层验证体系
1. **基础验证**: 设备存在性、在线状态、设备类型
2. **属性验证**: 属性支持性、值范围、数据类型
3. **约束验证**: 设备状态约束规则
4. **业务验证**: 特殊业务逻辑（如关机状态限制）

#### 验证规则示例
```javascript
// 空调约束规则
'mi_ac': {
  'target_temperature': {
    disallowedWhen: [
      { property: 'mode', value: 'dry' }  // 除湿模式不能调温度
    ]
  }
}
```

### 3. API集成

#### 请求格式
```javascript

{
```

## 🚀 使用指南

### 基本使用流程

1. **进入分组管理页面**
   - 导航到 "分组管理" 页面
   - 查看当前分组的设备列表

2. **选择要控制的设备**
   - 找到可控制设备（显示"设备控制"按钮）
   - 确保设备处于在线状态

3. **打开控制对话框**
   - 点击"设备控制"按钮
   - 查看当前设备状态和可用控制选项

4. **设置控制参数**
   - 根据设备类型调整各项参数
   - 系统会自动验证参数合法性

5. **执行控制命令**
   - 点击"执行控制"按钮
   - 查看控制结果反馈

6. **查看更新状态**
   - 控制成功后设备状态自动更新
   - 在设备列表中查看最新状态

### 错误处理指南

#### 常见错误及解决方案

| 错误类型 | 错误信息 | 解决方案 |
|---------|---------|---------|
| 设备离线 | "设备离线，无法控制" | 确保设备联网并处于工作状态 |
| 属性不支持 | "设备不支持属性 xxx" | 检查设备类型和控制选项 |
| 值超出范围 | "xxx 值必须在 xx 到 xx 之间" | 调整参数到合法范围内 |
| 状态约束 | "当 xxx 为 xxx 时，不能设置 xxx" | 先调整相关状态再设置目标属性 |
