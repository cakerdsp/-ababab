# 设备管理前后端集成总结

## 概述

本次修改将设备管理的前端页面与后端业务逻辑完全对齐，实现了真正的前后端交互。主要涉及分组管理、设备控制和环境数据分析三个核心功能模块。

## 主要修改内容

### 1. 主进程IPC处理器修改 (`src/main/index.js`)

#### 1.1 设备相关IPC处理器更新
将原有的 `deviceController` 架构更改为使用新的 `AccountManager` 架构：

**修改的IPC处理器：**
- `get-all-devices` - 获取所有设备
- `get-devices-by-brand` - 根据品牌获取设备  
- `get-controllable-devices` - 获取可控制设备
- `get-sensor-devices` - 获取传感器设备
- `get-device-control-options` - 获取设备控制选项
- `control-device` - 控制设备
- `refresh-devices` - 刷新设备状态

**新增的IPC处理器：**
- `get-devices-by-group` - 根据分组获取设备

#### 1.2 分组管理IPC处理器
完全重写传感器数据相关处理器，新增分组管理功能：

**新增的IPC处理器：**
- `get-all-groups` - 获取所有分组
- `create-group` - 创建分组
- `delete-group` - 删除分组
- `set-device-group` - 设置设备分组

#### 1.3 数据分析IPC处理器
新增传感器数据分析相关处理器：

**新增的IPC处理器：**
- `analyze-group-sensor-data` - 分析分组传感器数据
- `analyze-multiple-groups` - 分析多个分组数据
- `get-supported-sensor-types` - 获取支持的传感器类型
- `export-analysis-result` - 导出分析结果

#### 1.4 系统状态处理器更新
更新系统状态获取逻辑，使用新的管理器架构：

**修改的IPC处理器：**
- `get-system-status` - 获取系统状态
- `reconnect-sse` - 重新连接SSE

#### 1.5 默认分组初始化
在登录成功和自动登录成功后，自动创建"默认分组"：

```javascript
// 确保默认分组存在
try {
  const managers = accountManager.getDeviceManagers();
  const groups = managers.groupAPIManager.getAllGroups();
  const hasDefaultGroup = groups.some(group => group.gname === '默认分组');
  
  if (!hasDefaultGroup) {
    await managers.groupAPIManager.createGroup('默认分组');
    console.log('默认分组创建成功');
  }
} catch (error) {
  console.warn('创建默认分组失败:', error);
}
```

### 4. 新增数据分析类集成

#### 4.1 SensorDataAnalyzer类使用
环境报告页面通过以下IPC调用使用数据分析功能：

```javascript
// 分析指定分组的传感器数据
const result = await ipcRenderer.invoke('analyze-group-sensor-data', groupId);

// 分析结果包含：
// - temperature: 温度分析（平均值、极值、趋势、建议）
// - humidity: 湿度分析（平均值、极值、趋势、建议）  
// - pm25: PM2.5分析（平均值、极值、空气质量等级）
```

## 核心功能流程

### 1. 分组管理流程

#### 创建分组：
1. 用户输入分组名称
2. 前端验证（长度、重复性）
3. 调用`create-group` IPC
4. 后端通过API创建分组
5. 刷新分组列表
6. 自动切换到新创建的分组

#### 删除分组：
1. 用户选择要删除的分组
2. 确认对话框（默认分组保护）
3. 调用`delete-group` IPC
4. 后端删除分组并处理设备迁移
5. 切换到默认分组
6. 刷新分组列表

### 2. 设备管理流程

#### 设备控制：
1. 用户点击设备控制按钮
2. 调用`get-device-control-options`获取控制选项
3. 显示控制对话框
4. 用户设置控制参数
5. 调用`control-device`执行控制
6. 刷新设备状态

#### 设备移动：
1. 用户选择移动设备
2. 选择目标分组
3. 调用`set-device-group` IPC
4. 更新设备分组关系
5. 刷新当前分组的设备列表

### 3. 环境分析流程

#### 数据分析：
1. 用户选择分组
2. 调用`analyze-group-sensor-data` IPC
3. 后端获取分组内传感器设备
4. 收集历史数据进行分析
5. 计算统计指标和趋势
6. 生成评估和建议
7. 前端格式化显示结果

#### 报告导出：
1. 用户点击导出按钮
2. 调用`export-analysis-result` IPC
3. 后端格式化分析数据
4. 前端创建下载链接
5. 自动下载JSON格式报告
