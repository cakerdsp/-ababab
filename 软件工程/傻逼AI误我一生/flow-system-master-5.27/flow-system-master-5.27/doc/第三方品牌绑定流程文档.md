# Flow System 第三方品牌绑定流程文档

## 概述

本文档详细描述了 Flow System 应用中第三方品牌绑定的完整流程，包括用户界面操作、授权码获取、绑定和解绑操作的具体实现。

## 第三方品牌绑定流程架构图

```
用户进入设置页面
      ↓
查看支持的品牌列表 (小米/美的)
      ↓
点击"绑定账号"按钮
      ↓
弹出授权码输入对话框
      ↓
用户手动输入授权码
      ↓
调用绑定API (POST /auth/code)
      ↓
服务器验证授权码
      ↓
[成功] → 更新本地绑定状态 → 显示"已绑定"
[失败] → 显示错误信息
```

```javascript
// 加载绑定状态
async loadBindings() {
  try {
    this.refreshLoading = true
    const result = await window.api.getBindings()

    if (result && result.success && result.bindings) {
      // 更新绑定状态
      this.supportedBrands.forEach(brand => {
        const bindingInfo = result.bindings[brand.name]
        if (bindingInfo) {
          brand.isBound = bindingInfo.isBound
          brand.isExpired = bindingInfo.isExpired
        }
      })
    }
  } catch (error) {
    console.error('加载绑定状态错误:', error)
    this.$message.error('加载绑定状态失败')
  } finally {
    this.refreshLoading = false
  }
},
```

```javascript
// 确认绑定
async confirmBind() {
  if (!this.authCode.trim()) {
    this.$message.warning('请输入授权码')
    return
  }

  try {
    this.bindLoading = true
    const brandName = this.supportedBrands.find(b => b.displayName === this.currentBrandName)?.name

    const result = await window.api.bindThirdParty(brandName, this.authCode)

    if (result && result.success) {
      this.$message.success('绑定成功！')
      this.bindDialogVisible = false
      this.resetBindDialog()
      await this.loadBindings()
    } else {
      this.$message.error(result.message || '绑定失败')
    }
  } catch (error) {
    console.error('绑定错误:', error)
    this.$message.error('绑定请求失败')
  } finally {
    this.bindLoading = false
  }
},
```

#### 7.1 品牌绑定方法

```javascript
// 绑定第三方品牌账户 - 根据接口文档更新
async bindThirdPartyBrand(brandName, authCode) {
  try {
    if (!this.currentUser) {
      return { success: false, message: '用户未登录' };
    }

    // 验证品牌名是否支持
    const supportedBrands = ['xiaomi', 'midea'];
    if (!supportedBrands.includes(brandName)) {
      return { success: false, message: '不支持的品牌' };
    }

    // 调用API进行品牌绑定 - 根据接口文档使用code和brand参数
    const response = await this.apiRegistry.callAPI('bindThirdParty', {
      code: authCode,
      brand: brandName
    });

    if (response && response.status === 'success') {
      // 更新本地品牌状态
      if (!this.supportedBrands[brandName]) {
        this.supportedBrands[brandName] = {
          brandName: brandName,
          isBound: true,
          isExpired: false
        };
      } else {
        this.supportedBrands[brandName].isBound = true;
        this.supportedBrands[brandName].isExpired = false;
      }

      // 保存更新后的品牌状态
      this.dataStorage.saveSupportedBrands(this.supportedBrands);

      return { success: true, message: `${brandName}品牌绑定成功` };
    } else {
      return {
        success: false,
        message: response.message || '品牌绑定失败',
        errors: response.errors
      };
    }
  } catch (error) {
    console.error('品牌绑定错误:', error);
    return { success: false, message: error.message || '品牌绑定请求失败' };
  }
}
```

```javascript
// 调用API
async callAPI(apiName, data) {
  if (!this.apiPaths[apiName]) {
    throw new Error(`未知的API: ${apiName}`);
  }

  try {
    const response = await this.client.post(this.apiPaths[apiName], data);
    return response.data;
  } catch (error) {
    console.error(`API调用错误 (${apiName}):`, error);

    // 处理错误响应
    if (error.response) {
      // 服务器返回了错误响应
      return {
        success: false,
        message: error.response.data.message || `${apiName}请求失败`,
        status: error.response.status,
        errors: error.response.data.errors
      };
    } else if (error.request) {
      // 请求已发送但没有收到响应
      return {
        success: false,
        message: '服务器无响应'
      };
    } else {
      // 请求设置时发生错误
      return {
        success: false,
        message: error.message
      };
    }
  }
}
```

```javascript
async getAuthorizationCode(userId) {
  try {
    const response = await this.apiRegistry.callAPI('getAuthorizationCode', {
      userId: userId
    });

    if (response && response.authorizationCode) {
      return {
        success: true,
        authorizationCode: response.authorizationCode
      };
    } else {
      return {
        success: false,
```

## 关键接口信息

### 1. 绑定第三方品牌

- **API端点**: `POST http://172.19.15.2:3000/auth/code`
- **请求参数**:
  - `code`: 授权码 (string, 必填)
  - `brand`: 品牌名称 (string, 必填, 支持 xiaomi/midea)
- **认证**: 需要 Bearer Token

### 2. 解绑第三方品牌

- **API端点**: `POST http://172.19.15.2:3000/auth/unbind`
- **请求参数**:
  - `brand`: 品牌名称 (string, 必填)
- **认证**: 需要 Bearer Token

### 3. 获取绑定状态

- **API端点**: `GET http://172.19.15.2:3000/auth/bindings`
- **认证**: 需要 Bearer Token

## 授权码获取说明

目前的实现中，授权码是通过以下方式获取的：

1. **用户手动获取**: 用户需要访问第三方品牌(小米/美的)的官方授权页面，登录并获取授权码
2. **第三方API获取**: 系统提供 `/auth/getAuthorizationCode` 接口供第三方系统调用获取授权码

**授权码呈现方式**: 在绑定对话框中通过文本输入框显示，用户需要手动输入从第三方平台获取的授权码。

## 流程特点

1. **用户友好**: 清晰的UI指导用户完成绑定流程
2. **状态管理**: 实时更新绑定状态，支持过期状态显示
3. **错误处理**: 完善的错误提示和处理机制
4. **双向操作**: 支持绑定和解绑操作
