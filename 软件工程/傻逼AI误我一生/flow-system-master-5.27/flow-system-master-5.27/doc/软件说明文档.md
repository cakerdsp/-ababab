# Flow System 桌面应用软件说明文档

## 1. 项目概述

### 1.1 项目简介

Flow System 是一个基于 Electron + Vue 3 的桌面应用程序，主要用于用户认证管理和第三方品牌账号绑定。该应用提供了完整的用户登录、注册、自动登录、第三方品牌绑定/解绑等功能。

### 1.2 技术栈

- **前端框架**: Vue 3
- **桌面应用框架**: Electron 25.6.0
- **UI组件库**: Element Plus 2.8.8
- **HTTP客户端**: Axios 1.7.8
- **路由管理**: Vue Router 4.5.0
- **构建工具**: Electron Vite 1.0.27

## 2. 功能模块说明

### 2.1 用户认证模块

#### 2.1.1 用户注册

- **功能描述**: 用户可以通过用户ID和密码创建新账户
- **实现位置**: `src/renderer/src/views/login/index.vue`
- **后端接口**:`POST /auth/register`
- **请求参数**:
  - `userId`: 用户ID（必填）
  - `password`: 密码（必填）
- **响应格式**:
  ```json
  {
    "status": "success",
    "message": "User registered successfully",
    "data": { "success": true }
  }
  ```

#### 2.1.2 用户登录

- **功能描述**: 用户通过用户ID和密码登录系统
- **实现位置**: `src/renderer/src/views/login/index.vue`
- **后端接口**: `POST /auth/login`
- **请求参数**:
  - `userId`: 用户ID（必填）
  - `password`: 密码（必填）
- **特殊功能**:
  - 支持"记住我"选项
  - 登录成功后自动调整窗口大小
- **响应格式**:
  ```json
  {
    "status": "success",
    "message": "User logged in successfully",
    "data": {
      "token": "access_token",
      "refreshToken": "refresh_token"
    }
  }
  ```

#### 2.1.3 自动登录

- **功能描述**: 如果用户选择了"记住我"，应用重启时会自动登录
- **实现位置**: `src/class/AccountManager.js` 的 `initialize()` 方法
- **触发条件**:
  - 用户之前登录时选择了"记住我"
  - 本地存储中有有效的token和refreshToken
  - 登录凭据未过期（记住我：30天，普通：24小时）

#### 2.1.4 Token刷新

- **功能描述**: 当访问token过期时，自动使用refreshToken获取新的token
- **实现位置**: `src/class/AccountAPIRegistry.js` 的响应拦截器
- **后端接口**: `POST /auth/refresh-jwt`
- **自动触发**: 当API返回401状态码时

### 2.2 第三方品牌绑定模块

#### 2.2.1 支持的品牌

- **小米 (xiaomi)**: 小米智能设备生态
- **美的 (midea)**: 美的家电设备

#### 2.2.2 品牌绑定

- **功能描述**: 用户可以绑定第三方品牌账号以管理对应设备
- **实现位置**: `src/renderer/src/views/children/setting/index.vue`
- **后端接口**: `POST /auth/code`
- **请求参数**:
  - `code`: 授权码（必填）
  - `brand`: 品牌名称（必填，支持xiaomi或midea）
- **绑定流程**:
  1. 用户在设置页面点击"绑定账号"
  2. 弹出授权码输入对话框
  3. 用户输入从第三方平台获取的授权码
  4. 系统调用API完成绑定
  5. 更新本地绑定状态

#### 2.2.3 品牌解绑

- **功能描述**: 用户可以解绑已绑定的第三方品牌账号
- **实现位置**: `src/renderer/src/views/children/setting/index.vue`
- **后端接口**: `POST /auth/unbind`
- **请求参数**:
  - `brand`: 品牌名称（必填）

#### 2.2.4 绑定状态查询

- **功能描述**: 查询用户当前的品牌绑定状态
- **实现位置**: `src/class/AccountManager.js` 的 `loadUserBindings()` 方法
- **后端接口**: `GET /auth/bindings`
- **响应格式**:
  ```json
  {
    "status": "success",
    "message": "Fetched binding status",
    "data": [
      {
        "brand": "xiaomi",
        "isExpired": false
      },
      {
        "brand": "midea",
        "isExpired": true
      }
    ]
  }
  ```

### 2.3 本地存储模块

#### 2.3.1 存储内容

- **用户信息**: `flow_system_user`
- **访问令牌**: `flow_system_token`
- **刷新令牌**: `flow_system_refresh_token`
- **登录凭据**: `flow_system_credentials`
- **品牌绑定状态**: `flow_system_brands`
- **应用设置**: `flow_system_settings`

#### 2.3.2 存储管理

- **实现位置**: `src/class/AccountStorage.js`
- **主要方法**:
  - `saveUserAccount()`: 保存用户账户信息
  - `getUserAccount()`: 获取用户账户信息
  - `saveToken()`: 保存访问令牌
  - `getToken()`: 获取访问令牌
  - `saveRefreshToken()`: 保存刷新令牌
  - `getRefreshToken()`: 获取刷新令牌
  - `saveLoginCredentials()`: 保存登录凭据
  - `getLoginCredentials()`: 获取登录凭据
  - `hasValidSession()`: 检查是否有有效的登录状态
  - `clearUserData()`: 清除用户数据

## 3. 架构设计

### 3.1 整体架构

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   渲染进程        │    │    主进程        │    │   服务器端       │
│   (Vue3 App)    │    │  (Electron)     │    │  (HTTP API)     │
└─────────────────┘    └─────────────────┘    └─────────────────┘
         │                       │                       │
         │  IPC Communication    │   HTTP Requests       │
         │◄─────────────────────►│◄─────────────────────►│
         │                       │                       │
    ┌─────────┐             ┌─────────┐             ┌─────────┐
    │  UI层   │             │ IPC处理  │             │ API接口  │
    ├─────────┤             ├─────────┤             ├─────────┤
    │ 路由管理 │             │业务逻辑类 │             │用户认证  │
    ├─────────┤             ├─────────┤             ├─────────┤
    │组件管理  │             │本地存储  │             │品牌绑定  │
    └─────────┘             └─────────┘             └─────────┘
```

### 3.2 业务逻辑架构

```
AccountManager (账户管理器)
├── AccountStorage (本地存储管理)
├── AccountAPIRegistry (API注册器)
├── UserAccount (用户账户)
└── SupportedBrand (支持的品牌)
```

### 3.3 数据流向

1. **用户操作** → Vue组件
2. **Vue组件** → 通过window.api调用预加载脚本
3. **预加载脚本** → 通过IPC调用主进程
4. **主进程** → 调用业务逻辑类
5. **业务逻辑类** → 调用API注册器
6. **API注册器** → 发送HTTP请求到服务器
7. **服务器响应** → 原路返回到Vue组件

## 4. API接口说明

### 4.1 服务器配置

- **服务器地址**: `http://172.19.15.2:3000`
- **请求格式**: JSON
- **响应格式**: JSON
- **认证方式**: Bearer Token

### 4.2 接口列表

1. **用户注册**: `POST /auth/register`
2. **用户登录**: `POST /auth/login`
3. **第三方绑定**: `POST /auth/code`
4. **第三方解绑**: `POST /auth/unbind`
5. **获取绑定信息**: `GET /auth/bindings`
6. **刷新令牌**: `POST /auth/refresh-jwt`
7. **获取授权码**: `POST /auth/getAuthorizationCode`

详细接口文档请参考 `doc/接口文档.md`

## 5. 使用说明

### 5.1 开发环境搭建

```bash
# 安装依赖
npm install

# 开发模式运行
npm run dev

# 构建项目
npm run build

# 打包应用
npm run build:win  # Windows平台
npm run build:mac  # macOS平台
npm run build:linux # Linux平台
```

### 5.2 用户操作流程

#### 5.2.1 新用户注册流程

1. 启动应用，进入登录页面
2. 点击"注册"按钮切换到注册模式
3. 输入用户ID和密码（需确认密码）
4. 点击"注册"按钮提交注册信息
5. 注册成功后自动切换回登录模式

#### 5.2.2 用户登录流程

1. 在登录页面输入用户ID和密码
2. 可选择勾选"记住我"选项
3. 点击"登录"按钮
4. 登录成功后进入主应用界面

#### 5.2.3 第三方品牌绑定流程

1. 登录后进入设置页面
2. 在品牌列表中找到要绑定的品牌
3. 点击"绑定账号"按钮
4. 在弹出的对话框中输入授权码
5. 点击"确认绑定"完成绑定

#### 5.2.4 第三方品牌解绑流程

1. 在设置页面找到已绑定的品牌
2. 点击"解绑账号"按钮
3. 在确认对话框中点击"确定"
4. 完成解绑操作

### 5.3 自动登录说明

- 当用户登录时选择"记住我"选项时，下次启动应用会自动登录
- 自动登录凭据有效期：
  - 勾选"记住我"：30天
  - 未勾选"记住我"：24小时
- 如果自动登录失败，将显示登录页面

## 6. 错误处理

### 6.1 网络错误

- 当服务器无响应时，显示"服务器无响应"错误信息
- 当请求超时时，自动重试或提示用户检查网络连接

### 6.2 认证错误

- Token过期时自动尝试刷新
- 刷新失败时提示用户重新登录
- 无效的登录凭据时显示相应错误信息

### 6.3 业务错误

- 用户已存在时提示"用户已存在"
- 品牌绑定失败时显示具体错误原因
- 授权码无效时提示用户重新获取

## 7. 安全考虑

### 7.1 密码安全

- 密码在本地不存储，只在内存中临时使用
- 所有API请求使用HTTPS加密传输

### 7.2 Token管理

- 访问Token有较短的有效期
- 刷新Token用于延长会话
- Token在本地存储中加密保存

### 7.3 授权码安全

- 授权码使用一次性验证
- 授权码在传输过程中加密
- 过期的授权码自动失效
