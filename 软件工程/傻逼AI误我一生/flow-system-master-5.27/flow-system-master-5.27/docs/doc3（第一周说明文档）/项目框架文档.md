# 🌟 Flow System 项目框架文档

## 📋 项目概述

Flow System 是一个基于 Electron + Vue3 的跨平台桌面应用程序，主要用于设备管理和第三方品牌授权绑定。该项目采用前后端分离架构，客户端与独立服务器进行HTTP通信。

## 🏗️ 项目架构

### 技术栈
- **前端框架**: Vue 3.x + Vue Router 4.x
- **UI组件库**: Element Plus 2.x
- **桌面应用框架**: Electron 25.x
- **构建工具**: Vite + electron-vite
- **开发语言**: JavaScript
- **样式**: CSS3 + Less

### 整体架构
```
┌─────────────────┐    HTTP请求    ┌─────────────────┐
│                 │ ──────────── │                 │
│   Electron      │               │  独立服务器      │
│   客户端应用     │ ←──────────── │  (未实现)       │
│                 │    响应数据    │                 │
└─────────────────┘               └─────────────────┘
```

## 🔄 应用流程

### 启动流程
1. Electron主进程启动
2. 创建浏览器窗口
3. 加载Vue应用
4. 初始化业务管理器(AccountManager, DeviceController)
5. 检查自动登录状态
6. 显示相应页面(登录页或主页)

### 用户交互流程
1. **登录流程**: 用户输入凭据 → 验证 → 保存用户信息 → 跳转主页
2. **设备管理**: 查看设备 → 控制设备 → 接收状态更新
3. **第三方授权**: 选择品牌 → 获取授权码 → 完成绑定
4. **登出流程**: 清理用户数据 → 断开连接 → 返回登录页

## 🚪 页面结构

### 路由配置
```javascript
routes: [
  { path: "/", redirect: "/login" },
  { path: "/login", component: "登录页面" },
  { 
    path: "/main", 
    component: "主容器",
    children: [
      { path: "/desktop", component: "主页" },
      { path: "/account", component: "账号中心" },
      { path: "/device", component: "设备管理" },
      { path: "/group", component: "付款页面" },
      { path: "/report", component: "环境报告" },
      { path: "/third-party-auth", component: "第三方授权" }
    ]
  }
]
```

### 页面功能说明

#### 1. 登录页面 (`/login`)
- **文件位置**: `src/renderer/src/views/login/index.vue`
- **功能**: 用户登录、注册、忘记密码
- **特色功能**: 支持人脸登录、SSO登录(已注释)

#### 2. 主页 (`/desktop`)
- **文件位置**: `src/renderer/src/views/children/desktop/index.vue`
- **功能**: 系统概览、快捷操作

#### 3. 账号中心 (`/account`)
- **文件位置**: `src/renderer/src/views/children/account/index.vue`
- **功能**: 用户信息管理、第三方品牌设备绑定管理
- **支持品牌**: 美的(midea)、小米(xiaomi)

#### 4. 设备管理 (`/device`)
- **文件位置**: `src/renderer/src/views/children/device/index.vue`
- **功能**: 设备列表、设备控制、设备状态监控

#### 5. 第三方授权 (`/third-party-auth`)
- **文件位置**: `src/renderer/src/views/children/ThirdPartyAuth/index.vue`
- **功能**: 处理第三方品牌授权请求

#### 6. 其他页面
- **付款页面** (`/group`): 付款相关功能
- **环境报告** (`/report`): 环境数据报告

## 🔌 进程间通信(IPC)

### 主要IPC事件
- `check-auto-login`: 检查自动登录
- `login`: 处理登录请求
- `register`: 处理注册请求
- `logout`: 处理登出请求
- `bind-third-party`: 第三方品牌绑定
- `unbind-third-party`: 第三方品牌解绑
- `get-bindings`: 获取绑定信息
- `toMain`: 切换到主界面
- `minimizing`: 最小化窗口
- `expandWindow`: 展开/收缩窗口

## 🗄️ 数据管理

### 本地存储
- **用户信息**: 存储在本地文件中
- **设备数据**: 通过DataManager管理
- **会话数据**: 使用sessionStorage临时存储

### 业务类说明
- **AccountManager**: 用户账户管理、登录登出、第三方绑定
- **DeviceController**: 设备控制逻辑
- **DeviceManager**: 设备信息管理
- **DataManager**: 数据持久化管理
- **SSEService**: 服务端推送事件处理

## 🔐 安全机制

### 认证流程
1. 用户登录获取JWT Token
2. 后续请求携带Bearer Token
3. 第三方绑定需要授权码验证

### 数据保护
- 敏感数据本地加密存储
- 密码不明文保存
- 退出时清理所有用户数据

## 🌐 服务端接口

### 主要API端点
- `POST /auth/login`: 用户登录
- `POST /auth/register`: 用户注册
- `POST /mockapi/auth/getAuthorizationCode`: 获取授权码
- `POST /auth/code`: 绑定第三方账号

详细API文档请参考 `doc/授权码相关api.md`

## 📝 开发注意事项

1. **进程隔离**: Electron主进程和渲染进程分离，通过IPC通信
2. **安全配置**: 已禁用contextIsolation，生产环境需要启用
3. **跨平台**: 考虑不同操作系统的兼容性
4. **性能优化**: 大文件操作需要异步处理
5. **错误处理**: 完善的错误捕获和用户提示机制
