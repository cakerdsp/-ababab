## 调试输出说明

为了方便离线测试分组管理功能，我已经在系统的关键位置添加了详细的调试输出。调试信息使用不同的图标和颜色前缀来区分不同的组件和状态。

**重要更新：**
- ✅ 已修复Windows系统中文调试信息乱码问题
- ✅ 已添加admin账户离线调试模式支持
- ✅ 增加了SSE连接失败时的用户友好提示

## 调试标识说明

### 图标含义
- 🔍 **[调试]** - 主进程IPC处理器
- 🔧 **[后端调试]** - 后端业务逻辑
- 🎯 **[前端调试]** - 前端页面逻辑
- 🟡 **[离线调试]** - 离线调试模式操作
- ✅ **成功操作** - 操作成功完成
- ❌ **错误/失败** - 操作失败或异常

### 组件分类
- **IPC处理器** - 主进程中的通信处理
- **GroupAPI** - 分组管理器后端逻辑
- **前端页面** - Vue页面的用户交互逻辑

## 离线调试模式

### admin账户特殊处理
当使用 `admin` 账户登录时，系统会自动启用离线调试模式：
- SSE连接失败被视为正常现象
- 分组操作使用本地模拟数据
- 前端显示离线模式提示
- 所有操作标记为"离线模式"

### 离线模式特性
```
🟡 [离线调试] 检测到admin账户，启用离线调试模式
🟡 [离线调试] SSE连接失败是正常现象，将使用模拟数据
🟡 [离线调试] 离线模式：使用本地创建分组
```

## 中文乱码解决方案

系统已自动处理Windows控制台中文乱码问题：
- 自动设置控制台编码为UTF-8
- 设置代码页为65001
- 重写console方法确保中文正确显示
- 设置多个环境变量强制UTF-8编码
- 如果设置失败会显示警告提示

**验证方法：**
启动应用后，控制台应显示：
```
✅ 控制台UTF-8编码已配置
```

## admin账户完全离线模式

### 特殊处理流程
当使用admin账户登录时，系统执行以下特殊流程：
1. **跳过SSE连接** - 完全不尝试建立SSE连接
2. **启用离线模式** - 分组管理器自动启用离线模式
3. **本地数据操作** - 所有操作使用本地模拟数据
4. **跳过设备同步** - 不尝试从服务器获取设备状态

### 离线模式调试输出
```
🟡 [离线调试] 检测到admin账户，启用离线调试模式
🟡 [离线调试] 完全跳过SSE连接和设备控制器初始化
🟡 [离线调试] 分组管理器离线模式已启用
✅ [离线调试] admin账户登录完成，无需SSE连接
```
