# 页面显示问题紧急修复说明

## 🚨 问题描述
页面缩放功能导致页面完全不显示。

## 🛠️ 立即修复方法

### 方法一：清除本地存储缓存
在浏览器控制台执行以下命令：

```javascript
// 清除可能有问题的缩放设置
localStorage.removeItem('pageScale')

// 重置页面缩放
const appElement = document.getElementById('app')
if (appElement) {
  appElement.style.transform = ''
  appElement.style.width = ''
  appElement.style.height = ''
  appElement.style.transformOrigin = ''
}

// 刷新页面
location.reload()
```

### 方法二：快捷键重置
按 **F12** 打开开发者工具，在Console标签中粘贴上述代码并回车。

### 方法三：删除缓存文件
删除以下目录中的缓存：
```
C:\Users\86135\AppData\Roaming\flow-system\
```

1. 启动应用
2. 检查控制台是否有缩放相关日志
3. 尝试选择"100%"缩放选项
4. 如果页面仍然不显示，执行上述JavaScript命令

## 🔍 调试信息

查看控制台中的以下日志：
- `🔍 [调试] 应用缩放: X`
- `🔍 [调试] 找到app元素: true/false`
- `🔍 [调试] 缩放应用完成`

如果看到`找到app元素: false`，说明DOM还未加载完成。

## 📝 预防措施

下次启动时：
1. 直接选择"100%"选项
2. 避免选择极端缩放值（如50%或150%）
3. 如有问题，立即重置为100%
