# 设备管理代码清理和重构总结

## 概述
本次重构删除了与新实现重合的旧设备管理类，删除了传感器相关类（传感器被统一归为设备），并重写了数据分析类。同时将SystemManager改为向后兼容的包装器。

## 删除的文件列表

### 1. 重合的设备管理类
- **src/class/modules/device/DeviceRegistry.js** - 与DeviceStorageManager.js功能重合
- **src/class/modules/device/GroupManager.js** - 与DeviceGroupAPIManager.js功能重合  
- **src/class/modules/device/DeviceStatusManager.js** - 与DeviceSSEManager.js + DeviceStorageManager.js功能重合
- **src/class/modules/device/DeviceController.js** - 设备控制功能现在通过API直接实现

### 2. 传感器相关类
- **src/class/domain/device/Sensor.js** - 传感器被统一归为设备
- **src/class/domain/data/HistoryData.js** - 历史数据相关
- **src/class/modules/data/HistoryDataManager.js** - 历史数据管理

## 新建文件

### SensorDataAnalyzer.js
位置：`src/class/modules/data/SensorDataAnalyzer.js`
功能：分析指定分组中传感器设备的24小时数据

**主要功能：**
- 支持小米温湿度计（mi_temp_hum_sensor）和青萍空气质量检测仪（mi_air_sensor）
- 分析温度、湿度、PM2.5数据
- 计算温度趋势、湿度趋势
- 空气质量评级（按中国标准）
- 综合舒适度评分
- 支持多分组对比分析

**数据分析内容：**
- **温度分析**：平均温度、最高温度、最低温度、温度趋势
- **湿度分析**：平均湿度、最高湿度、最低湿度、湿度趋势
- **PM2.5分析**：平均PM2.5值、最低PM2.5值、最高PM2.5值
- **空气质量评级**：优、良、轻度污染、中度污染、重度污染、严重污染
- **综合舒适度**：基于温度、湿度、PM2.5的综合评分和等级

## 新的架构说明

### 数据分析流程
1. **通过AccountManager获取数据分析器**：
   ```javascript
   const analyzer = accountManager.getDeviceManagers().dataAnalyzer;
   ```

2. **分析指定分组的传感器数据**：
   ```javascript
   const result = await analyzer.analyzeGroupSensorData(groupId);
   ```

3. **多分组对比分析**：
   ```javascript
   const results = await analyzer.analyzeMultipleGroups([groupId1, groupId2]);
   ```

### 前端集成接口

#### 通过index.js便捷方法：
```javascript
const flowSystem = require('./src/class');

// 分析分组传感器数据
const analysisResult = await flowSystem.deviceManagement.analysis.analyzeGroup(groupId);

// 获取支持的传感器类型
const sensorTypes = flowSystem.deviceManagement.analysis.getSupportedSensorTypes();

// 导出分析结果
const exportData = flowSystem.deviceManagement.analysis.exportResult(analysisResult);
```

#### 直接使用管理器：
```javascript
const { AccountManager, SensorDataAnalyzer } = require('./src/class');

const accountManager = new AccountManager();
const analyzer = accountManager.getDeviceManagers().dataAnalyzer;

// 分析操作
const result = await analyzer.analyzeGroupSensorData(groupId);
```

## 传感器类型支持

### 小米温湿度计 (mi_temp_hum_sensor)
- 属性：temperature, humidity, time
- 分析：温度和湿度的统计和趋势

### 青萍空气质量检测仪 (mi_air_sensor)  
- 属性：pm25, temperature, humidity, time
- 分析：PM2.5、温度、湿度的统计，空气质量评级

## 空气质量评级标准
- **优**：PM2.5 ≤ 35 μg/m³
- **良**：35 < PM2.5 ≤ 75 μg/m³  
- **轻度污染**：75 < PM2.5 ≤ 115 μg/m³
- **中度污染**：115 < PM2.5 ≤ 150 μg/m³
- **重度污染**：150 < PM2.5 ≤ 250 μg/m³
- **严重污染**：PM2.5 > 250 μg/m³

## 舒适度评级标准
- **温度最佳范围**：20-26°C
- **湿度最佳范围**：40-60%
- **PM2.5最佳**：≤ 35 μg/m³

综合舒适度评分0-100分，分为6个等级：
- 非常舒适 (90-100分)
- 舒适 (80-89分)
- 较舒适 (70-79分)
- 一般 (60-69分)
- 不太舒适 (40-59分)
- 不舒适 (0-39分)

## 注意事项

1. **数据获取**：优先从API获取24小时数据，失败时回退到本地存储
2. **实时更新**：传感器数据通过SSE实时更新到本地存储
3. **性能考虑**：大量数据分析时建议在后台执行
4. **错误处理**：数据不足时返回空的分析结果而不报错
5. **扩展性**：支持新增传感器类型，只需更新sensorTypes配置
