# 退出登录问题解决方案

## 🔍 问题描述

用户反馈退出登录时无法删除本地存储文件，特别是`flow_system_device_*.json`文件，这些文件位于`C:\Users\86135\AppData\Roaming\flow-system\storage`目录中。

## 🚨 根本原因分析

### 1. 前端问题
- **退出按钮没有调用后端API**：前端的退出登录只是跳转到登录页面，没有真正调用`window.api.logout()`
- **缺少完整的清理流程**：只是简单的路由跳转，没有执行数据清理

### 2. 后端问题  
- **AccountManager.logout()方法被调用，但前端没有调用**
- **文件删除逻辑正常，但调试信息不足**

## ✅ 解决方案

### 1. 修复前端退出逻辑

#### 修复侧边栏退出功能 (`src/renderer/src/components/sidebar/index.vue`)
```javascript
// 修改前：只是跳转页面
this.$router.push(path)

// 修改后：真正调用logout API
.then(async () => {
  console.log('🔥 [FRONTEND LOGOUT] Starting logout process from sidebar...');
  
  try {
    // 调用后端logout API
    const logoutResult = await window.api.logout();
    console.log('🔥 [FRONTEND LOGOUT] Logout API result:', logoutResult);
    
    if (logoutResult.success) {
      this.$message.success('退出登录成功');
      
      // 清理前端本地存储
      localStorage.clear();
      sessionStorage.clear();
      
      this.$router.push('/login');
    } else {
      this.$message.error(logoutResult.message || '退出登录失败');
    }
  } catch (error) {
    console.error('🔥 [FRONTEND LOGOUT] ❌ Logout error:', error);
    this.$message.error('退出登录时发生错误');
    // 即使API调用失败，也尝试跳转到登录页面
    this.$router.push('/login');
  }
})
```

```javascript
ipcMain.handle('logout', async () => {
  try {
    console.log('🔥 [MAIN LOGOUT] ==========================================');
    console.log('🔥 [MAIN LOGOUT] Received logout request from frontend...');
    
    const { accountManager, deviceController } = require('../class');
    
    // 清理设备控制器
    await deviceController.logout();
    
    // 执行账户管理器退出
    const result = await accountManager.logout();
    console.log('🔥 [MAIN LOGOUT] Account manager logout result:', result);
    
    return result;
  } catch (error) {
    console.error('🔥 [MAIN LOGOUT] ❌ Logout processing failed:', error);
    return { success: false, message: error.message || 'Logout processing failed' };
  }
});
```

## 📊 删除的文件类型

退出登录时会删除以下文件：
- `flow_system_brands.json` - 品牌绑定信息
- `flow_system_credentials.json` - 登录凭据
- `flow_system_devices.json` - 设备列表数据
- `flow_system_device_groups.json` - 设备分组数据
- `flow_system_device_*.json` - 单个设备状态文件（如`flow_system_device_midea_midea_ac_eyfpek.json`）
- `flow_system_refresh_token.json` - 刷新令牌
- `flow_system_settings.json` - 应用设置
- `flow_system_sse_connection_id.json` - SSE连接ID
- `flow_system_token.json` - 访问令牌
- `flow_system_user.json` - 用户信息

9. **返回结果** → 前端收到成功响应
