API 文档：用户认证部分

基础信息

**API 名称** ：用户认证 API

**API 目标** ：提供用户注册、登录、第三方账号绑定和解绑功能

**协议** ：HTTP/HTTPS

**服务器地址** ：**http://1**7**2.**19**.**15**.**2**:3000**

**请求格式** ：JSON

**响应格式** ：JSON

请求头

**Content-Type** ：**application/json**

Authorization ：Bearer `<token>`（需要认证的接口）

API 列表

1. 用户注册

**请求方法** ：POST

**请求路径** ：**http://1**7**2.**19**.**15**.**2**:3000/auth/register**

**请求参数** ：

**userId** ：string，必填，用户 ID

**password** ：string，必填，用户密码

**响应示例** ：

成功响应（200 OK）：

**{  "status": "success",  **

 **"message": "User registered successfully",  "**

**“**data": {    "success": true  }

**}**

验证失败（400 Bad Request）：

**{  "status": "error",  **

 **"errors": [    **

**{      "msg": "userId is required"    },    **

   **{ ** "msg": "password is required"    }

  **]**

**}**

用户已存在（409 Conflict）：

**{  "status": "error",  **

**"message": "User already exists"**

**}**

2. 用户登录

**请求方法** ：POST

**请求路径** ：**http://1**7**2.**19**.**15**.**2**:3000/auth/login**

**请求参数** ：

**userId** ：string，必填，用户 ID

**password** ：string，必填，用户密码

**响应示例** ：

成功响应（200 OK）：

**{  "status": "success",  **

**"message": "User logged in successfully", **

** "data": {   **

  **"token": "access_token",**

  ** **"refreshToken": "refresh_token"

**}**

**}**

验证失败（400 Bad Request）：

**{  "status": "error", **

** "errors": [    **

  **{      "msg": "userId is required"    },    {      "msg": "password is required"    } **

** ]**

**}**

登录失败（401 Unauthorized）：

**{  "status": "error", **

** "message": "Invalid userId or password"**

**}**

3. 绑定第三方账号（需JWT认证）

**请求方法** ：POST

**请求路径** ：**http://1**7**2.**19**.**15**.**2**:3000/auth/code**

**请求头**：
  Authorization: Bearer `<accessToken>`

**请求参数** ：

**code** ：string，必填，授权码

**brand** ：string，必填，品牌名（**xiaomi** 或 **midea**）

**响应示例** ：

验证失败（401 Unauthorized）：

**{  "status": "error",**

** "errors":** "msg": "**Missing authorization header**"

**}**

**{  "status": "error",**

** "errors":** "msg": "**Invalid or expired token**"

**}**

成功响应（200 OK）：

**{  "status": "success",  **

 **"message": "Code exchanged successfully",**

**}**

请求参数错误（400 Bad Request）：

**{  "status": "error",**

** "errors": [    **

  **{      "msg": "code is required"    },       **

**{      "msg": "Invalid brand"    }  **

**]**

**}**

服务错误（500 Internal Server Error）：

**{  "status": "error",**

**  "message": "Internal server error"**

**}**

4. 解绑第三方账号（需JWT认证）

**请求方法** ：POST

**请求路径** ：**http://1**7**2.**19**.**15**.**2:**3000/auth/unbind**

**请求头**：
  Authorization: Bearer `<accessToken>`

**请求参数** ：

**brand** ：string，必填，品牌名（**xiaomi** 或 **midea**）

**响应示例** ：

验证失败（401 Unauthorized）：

**{  "status": "error",**

** "errors":** "msg": "**Missing authorization header**"

**}**

**{  "status": "error",**

** "errors":** "msg": "**Invalid or expired token**"

**}**

成功响应（200 OK）：

**{  "status": "success",**

**  "message": "Account unbound successfully",**

**  "data": {    "success": true  }**

**}**

验证失败（400 Bad Request）：

**{  "status": "error",**

**  "errors": [    **

  **   {   ** "msg": "Invalid brand"    }

**]**

**}**

操作失败（400 Bad Request）：

**{  "status": "error",**

**  "message": "Operation failed"**

**}**

5. 获取授权码（向第三方api）

**请求方法**：POST
请求路径：/auth/getAuthorizationCode

**请求参数**：

userId（string，必填）：用户ID

**响应示例**：
成功响应（200 OK）：

**{  "authorizationCode": "随机生成的授权码"}**

用户不存在（404 Not Found）：

**{  "error": "User not found"}**

：

服务错误（500 Internal Server Error）：

**{  "error"**: "Internal server error"

**}**

6. 刷新访问令牌

**请求方法**：POST
请求路径：/auth/refresh-jwt

**请求参数**：

refreshToken（string，必填）：刷新令牌

**响应示例**：

成功响应（200 OK）：

**{  "status": "success",**

**  "message": "Token refreshed successfully",**

**  "data": {    "token": "新的accessToken"  }}**

验证失败（400 Bad Request）：

**{  "status": "error",**

**"errors": [    **

**{   ** "msg": "**refreshToken is required**"    }

**]**

**}**

令牌无效（401 Unauthorized）：

**{  "status": "error",**

**  "message": "Invalid or expired refreshToken"**

**}**

7. 获取绑定信息（需JWT认证）

**请求方法** ：GET

**请求路径** ：**http://1**7**2.**19**.**15**.**2:**3000/auth/**bindings

**请求头**：
  Authorization: Bearer `<accessToken>`

**请求参数** ：

无

**响应示例** ：

验证失败（401 Unauthorized）：

**{  "status": "error",**

** "errors":** "msg": "**Missing authorization header**"

**}**

**{  "status": "error",**

** "errors":** "msg": "**Invalid or expired token**"

**}**

成功响应（200 OK）：

**{  "status": "success",**

**  "message": **"Fetched binding status**",**

**  "data": **[

  **{**

   ** "brand": "xiaomi",**

   **"isExpired": false**

  **},**

  **{**

   ** "brand": "midea",**

   **"isExpired": true**

  **}**

 **  **]

**}**

**注：绑定后第三方token已过期，或从未绑定，均返回isExpired ：false**

服务错误（500 Internal Server Error）：

**{  "status": "error",**

**  "message": "Internal server error"**

**}**

错误状态码说明

**200 OK** ：请求成功

**400 Bad Request** ：请求参数错误

**401 Unauthorized** ：未授权/令牌失效

404 Not Found ：资源不存在

**409 Conflict** ：资源冲突（用户已存在）

**500 Internal Server Error** ：服务器内部错误
