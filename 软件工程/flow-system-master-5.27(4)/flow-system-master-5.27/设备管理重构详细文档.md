# 设备管理重构详细文档

## 概述
本次重构主要完成了设备管理相关功能的集成，包括：
1. 在AccountAPIRegistry.js中添加设备相关API
2. 创建新的SSE管理器类
3. 创建设备存储管理类
4. 创建分组API管理类
5. 在AccountManager中集成这些功能
6. 更新导出接口

### 2. 新建 DeviceSSEManager.js
**文件路径**: `src/class/modules/device/DeviceSSEManager.js`

**新建文件，主要功能**:
- 管理SSE连接的建立和断开
- 处理设备状态更新消息
- 处理传感器数据更新消息
- 提供事件处理器注册和注销机制
- 与服务端进行SSE连接的退出通知

**核心方法**:
- `initialize(userId, deviceStorage)`: 初始化SSE管理器
- `connect()`: 建立SSE连接
- `disconnect()`: 断开SSE连接
- `handleDeviceStatusUpdate(deviceData)`: 处理设备状态更新
- `handleSensorDataUpdate(sensorData)`: 处理传感器数据更新
- `notifyExit(apiRegistry)`: 通知服务端退出连接

### 3. 新建 DeviceStorageManager.js
**文件路径**: `src/class/modules/device/DeviceStorageManager.js`

**新建文件，主要功能**:
- 本地存储设备状态信息
- 管理设备与分组的映射关系
- 提供设备数据的增删改查功能
- 支持按分组、品牌、类型等条件查询设备

**核心方法**:
- `initialize()`: 初始化存储管理器
- `storeAllDevices(devicesArray)`: 存储所有设备数据
- `updateDeviceStatus(did, statusUpdates)`: 更新设备状态
- `setDeviceGroup(did, groupId)`: 设置设备分组
- `getAllDevices()`: 获取所有设备
- `getDevicesByGroup(groupId)`: 按分组获取设备
- `getDeviceStats()`: 获取设备统计信息

### 4. 新建 DeviceGroupAPIManager.js
**文件路径**: `src/class/modules/device/DeviceGroupAPIManager.js`

**新建文件，主要功能**:
- 与服务端进行分组相关的API交互
- 本地分组数据缓存管理
- 提供分组的创建、删除、查询功能
- 提供设备分组设置功能

**核心方法**:
- `initialize()`: 初始化分组管理器
- `createGroup(gname)`: 创建新分组
- `deleteGroup(gid)`: 删除分组
- `setDeviceGroup(deviceId, groupId)`: 设置设备分组
- `syncGroupsFromServer()`: 从服务端同步分组数据
- `getAllGroups()`: 获取所有分组
- `getGroupStats()`: 获取分组统计信息

## 功能流程说明

### 1. 登录流程
1. 用户登录成功后，AccountManager自动调用`initializeDeviceManagement(userId)`
2. 初始化设备存储管理器，从本地加载现有设备数据
3. 初始化分组API管理器，从服务端同步分组信息
4. 调用API获取所有设备状态，并存储到本地（包含分组信息）
5. 初始化SSE管理器，设置消息处理器
6. 建立SSE连接，准备接收实时设备状态更新

### 2. 设备状态更新流程
1. 服务端通过SSE推送设备状态更新
2. DeviceSSEManager接收消息并解析
3. 调用DeviceStorageManager更新本地设备状态
4. 触发设备状态更新事件，通知前端界面更新

### 3. 分组管理流程
1. 前端调用分组相关API（通过DeviceGroupAPIManager）
2. 与服务端进行API交互（创建/删除/修改分组）
3. 更新本地分组缓存
4. 同步更新设备的分组信息

### 4. 退出登录流程
1. 调用logout方法
2. 通知服务端关闭SSE连接
3. 断开本地SSE连接
4. 重置所有设备管理组件
5. 清理本地存储数据

## 前端集成使用

### 通过便捷方法访问
```javascript
const { deviceManagement } = require('./src/class');

// 获取所有设备
const devices = deviceManagement.storage.getAllDevices();

// 获取所有分组
const groups = deviceManagement.groups.getAll();

// 创建新分组
await deviceManagement.groups.create('客厅设备');

// 设置设备分组
await deviceManagement.groups.setDeviceGroup('device123', 'group456');

// 注册SSE事件处理器
deviceManagement.sse.registerHandler('deviceStatusUpdated', (data) => {
  console.log('设备状态更新:', data);
});
```

### 通过AccountManager访问
```javascript
const { accountManager } = require('./src/class');

// 获取设备管理器实例
const managers = accountManager.getDeviceManagers();

// 直接操作管理器
const devices = managers.storageManager.getAllDevices();
const groups = await managers.groupAPIManager.createGroup('新分组');
```

## 注意事项

1. **登录依赖**: 设备管理功能依赖于用户登录，只有在登录成功后才会初始化
2. **SSE连接**: SSE连接失败不会影响其他功能，但不会收到实时更新
3. **数据同步**: 本地数据会在登录时从服务端同步，确保数据一致性
4. **错误处理**: 所有API调用都包含完善的错误处理机制
5. **资源清理**: 退出登录时会正确清理所有资源，避免内存泄漏
