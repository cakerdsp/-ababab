## 🚀 如何查看页面

### 方法1: 开发环境启动
```bash
# 1. 导航到正确的项目目录
cd D:\flow-system-master-5.27\flow-system-master-5.27

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev
```

### 方法2: 构建后运行
```bash
# 1. 构建项目
npm run build

# 2. 启动预览
npm run start
```

### 方法3: 直接运行可执行文件
如果已经构建了应用，可以在 `out/` 目录找到可执行文件直接运行。

## 🎮 页面导航方式

### 1. 自动导航
- 应用启动 → 自动跳转到登录页
- 登录成功 → 自动跳转到主页(`/desktop`)

### 2. 手动导航
在开发环境中，可以直接修改浏览器地址栏：
- `http://localhost:9080/#/login` - 登录页
- `http://localhost:9080/#/desktop` - 主页
- `http://localhost:9080/#/account` - 账号中心
- `http://localhost:9080/#/device` - 设备管理
- `http://localhost:9080/#/group` - 付款页面
- `http://localhost:9080/#/report` - 环境报告
- `http://localhost:9080/#/third-party-auth` - 第三方授权

### 3. 应用内导航
通过界面上的按钮、菜单、链接进行页面跳转

## 🔧 页面调试

### 开启开发者工具
在开发环境下，应用会自动打开开发者工具，可以：
- 查看控制台日志
- 检查网络请求
- 调试Vue组件
- 修改CSS样式

### 热重载
开发环境支持热重载，修改代码后页面会自动刷新。

## 📱 响应式支持

所有页面都支持响应式布局，可以在不同分辨率下正常显示：
- 桌面端：1200px+
- 平板端：768px - 1199px  
- 移动端：< 768px

## 🎨 UI组件库

项目使用 Element Plus 作为UI组件库，提供了丰富的组件：
- 按钮、输入框、表单
- 卡片、对话框、消息提示
- 表格、分页、加载状态
- 图标、布局组件

## 🚨 注意事项

1. **路由模式**: 项目使用Hash路由模式，URL中会包含`#`符号
2. **开发端口**: 默认开发端口为9080，如果端口被占用会自动分配其他端口
3. **页面权限**: 部分页面需要登录后才能访问
4. **数据模拟**: 由于后端服务未实现，部分功能使用模拟数据

## 🔍 常见问题

### Q: 页面空白或加载失败？
A: 检查控制台错误信息，确保所有依赖已正确安装

### Q: 路由跳转不生效？
A: 确认路由配置正确，检查Vue Router版本兼容性

### Q: 样式显示异常？
A: 检查CSS文件路径，确认Element Plus主题加载正常

### Q: 开发环境无法启动？
A: 检查Node.js版本，确保满足项目要求的最低版本
